The problem

Raw OpenStreetMap is a cloud of poles. We turn it into intersections.

A single junction holds several signal poles, tagged inconsistently, with no deduplication and no classification. Our pipeline clusters the poles, merges divided-road duplicates, classifies the signal type, and emits one clean record per real intersection — with a nearest street and a confidence score.

About MobilityMetric

One clean record per signalized intersection, extracted from OpenStreetMap and deduplicated into one point per real junction — 225 US cities across all 50 states and DC, plus 271 cities across 41 European countries. This page runs a live 1,000-record sample; the full dataset is maintained continuously.

How the data is built

  1. Pull traffic-signal nodes from OpenStreetMap for the area.
  2. Cluster and deduplicate overlapping poles into one point per real intersection.
  3. Classify each by signal type — vehicular, pedestrian, both, HAWK beacon, or level crossing.
  4. Enrich with the nearest street, and (US) per-arm approach geometry and speed limits.
  5. Fuse with official city open-data where it exists, and score confidence.
  6. Assign a stable, location-based ID that survives data refreshes.

What each record carries

Stable ID, coordinates, signal type, nearest street, confidence score, source, and OSM last-edited date — plus, for the US, approach count, per-arm bearings and speed limits. Exportable as GeoJSON or CSV.

Built for

V2X / C-ITS RSU placement and SPaT/MAP inventories, traffic simulation (SUMO, VISSIM), HD maps, routing, and pedestrian-accessibility audits.

Built by Jigar Vegad — MSc Transportation Systems, TU Munich (ITS / V2X). Full coverage, other regions, and custom fields are available on request.
