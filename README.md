# mobilitymetric.me

Public portfolio and live demos of open mobility datasets — signalized
intersections, low-emission zones, and EV charging — built from
OpenStreetMap and public sources.

Each demo lets you search a region and preview a sample of the data on a map,
so you can check coverage and accuracy for yourself.

**Live site:** https://mobilitymetric.me

> This repository contains the public frontend only.
> The data-processing engine is not part of this repository.
